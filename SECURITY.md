# Security Policy

This policy covers every thetaplex repository that doesn't have its own
`SECURITY.md`.

## Supported versions

Only the latest release on `main` gets security fixes.

## Reporting a vulnerability

Report privately, not in a public issue:

- open a private advisory from the repository's **Security** tab
  (**Report a vulnerability**), or
- email support@thetaplex.com.

Include the repository, what you did, and what happened. You'll get a reply
within 7 days.
